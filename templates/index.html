Section 1

Abstract

This project presents a machine learning web application that predicts residential property prices across India using Stratified Linear Regression — separate regression models trained per location tier (Rural, Tier-2, Metro). The system integrates reverse geocoding to automatically detect the property's location tier from a map pin, enabling realistic, tier-appropriate price estimation.

The application is built with a Flask backend, served via Gunicorn, deployed on Render, and features a modern dark-theme frontend with an interactive Leaflet.js map, Chart.js analytics dashboard, and a property comparison tool.

Section 2

Problem Statement

House price estimation in India is highly non-uniform. A 1000 sq ft apartment in Mumbai can cost ₹1.2 Cr while the same property in a village may cost ₹8 Lakh. Traditional single-model regression fails to capture this tier-based price gap.

The goal of this project is to build a system that:

① Accepts property details (area, bedrooms, type, furnishing)
② Auto-detects location tier via map pin
③ Applies the appropriate regression model for that tier
④ Returns a realistic price estimate with confidence range

Section 4

Methodology

Stratified Linear Regression was used — three separate LR models, one per location tier. This approach handles the non-linear jump in prices between tiers while keeping each individual model linear and interpretable.

Price = β₀ + β₁·sqft + β₂·beds + β₃·baths + β₄·prop_type + β₅·furnish

Rural model: β₁ = 6.11 (₹/sqft scale)
Tier-2 model: β₁ = 41.42 (₹/sqft scale)
Metro model: β₁ = 152.38 (₹/sqft scale)

Each model uses StandardScaler (zero mean, unit variance) before fitting to ensure all features contribute proportionally to the regression.

Location tier is determined at prediction time via reverse geocoding (Nominatim API) — the user pins a location on the map and the backend classifies it into Rural / Tier-2 / Metro automatically.

Section 7

Conclusion

Key Achievements

This project successfully demonstrates end-to-end machine learning deployment. The stratified Linear Regression approach achieves R² scores above 0.94 across all tiers, with logically consistent predictions — furnishing, property type, and location tier all correctly influence the output price.

The system handles edge cases (too many beds for small area), provides confidence ranges, includes a market analytics dashboard, a comparison tool, and is publicly accessible via Render deployment.

Future scope: Integrate real scraped data from 99acres/MagicBricks, add Polynomial Regression comparison, and include neighbourhood-level granularity using pincode-based pricing.
